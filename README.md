# 누수닥터 PRO 3.0

외부 라이브러리·서버·카메라/OCR 없이 작동하는 수동 압력 기록 PWA입니다.

## 설치 및 배포
이 폴더의 파일을 GitHub 저장소 `rlgnsekf-ux/leakdoctor-personal`의 main 루트에 업로드합니다. Settings → Pages → Deploy from a branch → main / (root)로 설정합니다. HTTPS에서 처음 접속한 뒤 오프라인 사용이 가능합니다. 스마트폰 브라우저의 홈 화면 추가/앱 설치 메뉴를 이용하세요. 로컬 파일 직접 열기는 설치·오프라인 기능을 지원하지 않습니다.

## 데이터와 백업
기존 앱 삭제 전 기존 앱의 데이터를 먼저 내보내 보관하세요. 기존 저장 키는 수정하거나 삭제하지 않습니다. PRO 3.0은 `leakdoctor.pro3.v1` 키를 사용하며 기존 버전 데이터 자동 변환은 지원하지 않습니다. 브라우저 데이터 삭제·시크릿 모드 종료·기기 변경 시 데이터가 사라질 수 있습니다. 정기적으로 JSON 백업을 내려받으세요. 복원은 PRO 3.0 형식만 지원하며 기존 기록에 새 ID로 추가합니다. 중복 파일을 복원하면 현장이 중복 추가됩니다. 여러 탭에서 동시에 편집하지 마세요.

## 사용
새 현장에 고객과 주소·작업일지를 입력합니다. 회차별 배관/매체/단위/시작·종료 온도/격리·안정화 조건 및 참고 기준을 설정합니다. 타이머 시작 후 경과 시간과 압력을 직접 기록합니다. 타이머를 사용하지 않고 경과 분을 직접 입력해도 됩니다. 측정값 수정·삭제가 가능합니다. 측정 후 단위 변경은 새 회차에서 진행합니다.

하강량 = 최초 압력 − 최종 압력. 시간당 하강률 = 하강량 × 60 ÷ 경과 분. 시간순 첫·마지막 측정값을 이용합니다. 음수는 압력 상승입니다. 두 허용 기준을 모두 입력해야 비교하며 하나라도 초과하면 추가 확인 필요로 표시합니다. 같은 단위 회차만 그래프에 함께 표시되며 전체 회차는 비교표로 확인할 수 있습니다. 인쇄는 선택한 현장·현재 회차의 상세 측정값·전체 회차 요약을 출력합니다. 다른 회차 상세는 해당 회차 선택 후 인쇄하세요.

사용자 기준은 공인 합격 기준이 아닙니다. 결과는 누수 확정 진단이 아니며 시험압력이나 시험 절차를 제안하지 않습니다. 실제 작업 조건·온도·계기·격리·안정화 영향을 검토하세요.
