누수닥터 PRO 3.1 설치 안내

1. GitHub 저장소 rlgnsekf-ux/leakdoctor-personal 에서 Add file > Upload files를 선택합니다.
2. 이 폴더의 index.html, app.js, style.css, manifest.webmanifest, sw.js, icon.svg, icon-192.png, icon-512.png 파일을 업로드해 기존 파일을 교체합니다.
3. Commit changes를 누른 후 GitHub Pages 배포를 기다립니다.
4. https://rlgnsekf-ux.github.io/leakdoctor-personal/ 을 Chrome으로 열어 새로고침합니다.
5. Chrome 메뉴 > 홈 화면에 추가 > 설치를 선택합니다.

기존 PRO 3.0 데이터는 같은 주소/브라우저에 남아 있으면 자동으로 읽도록 설계했습니다. 앱 삭제 전에 반드시 JSON 백업하세요.

시험 결과는 참고용이며 실제 누수 유무, 누수량 또는 누수 규모를 확정하지 않습니다. 압축 기체 시험은 배관·부속의 적합성과 안전 절차를 확인하세요.
